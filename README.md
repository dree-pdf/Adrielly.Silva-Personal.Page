# Atividade Prática 2 - Desenvolvimento de Página Pessoal

**Disciplina:** GAC116 - Programação Web  
**Modalidade:** Individual  

## 🎯 Objetivo do Projeto

Este repositório contém o desenvolvimento de uma Página Pessoal (Portfólio Web) construída para aplicar os conceitos práticos de estruturação, estilização e responsividade vistos na disciplina. 

O principal objetivo tecnológico desta atividade é a **comparação prática entre dois diferentes frameworks CSS**. Para isso, o mesmo conteúdo e a mesma identidade visual (tons terrosos e pastéis) foram implementados em duas versões distintas do projeto:
1. Uma versão utilizando **Bootstrap 5**.
2. Uma versão utilizando **Materialize CSS**.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias e linguagens:

*   **HTML5:** Estruturação semântica do conteúdo.
*   **CSS3:** Customização de estilos, variáveis de cores (paleta terrosa) e sobrescrita de padrões dos frameworks.
*   **JavaScript (Vanilla):** Lógica para manipulação do DOM e armazenamento local (`localStorage`) das preferências de tema.
*   **Bootstrap 5:** Framework CSS utilizado na primeira versão.
*   **Materialize CSS:** Framework CSS baseado no Material Design utilizado na segunda versão.

## ✨ Funcionalidades

Ambas as versões do portfólio atendem aos seguintes requisitos técnicos:

*   **Totalmente Funcional e Responsivo:** A página se adapta perfeitamente a diferentes tamanhos de tela (mobile, tablet e desktop) utilizando os sistemas de grid de cada framework.
*   **Alternância de Tema (Dark/Light Mode):** Implementação de tema claro e escuro. A escolha do usuário é salva no navegador via `localStorage`, mantendo a consistência da interface ao recarregar a página.
*   **Identidade Visual Consistente:** Estilo visual focado em tons terrosos e pastéis, garantindo uma boa experiência de navegação e leitura.
*   **Informações Reais:** Apresentação de dados, habilidades e projetos acadêmicos e profissionais reais.
